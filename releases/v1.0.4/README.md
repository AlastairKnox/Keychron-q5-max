# v1.0.4 - Downward colour sweep

Linux mode combines the typing heatmap on the main keyboard with a continuous top-to-bottom rainbow on the 17 numpad keys and circle/triangle/square. The sweep runs while typing and idle. Existing Fn highlights, Caps Lock warning and Escape status take priority. Saved brightness, saturation and speed apply; normal lighting off and sleep remain available. Stock modes and typing macros are unchanged.

Firmware build and regression checks passed, including exact LED footprint using the board geometry, downward movement, frame limits and indicator priority. Hardware appearance and sleep/wake require checking after flashing. No flashing performed.
