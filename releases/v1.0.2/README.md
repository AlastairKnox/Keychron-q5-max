# v1.0.2 - Terminal shortcuts and calculator

In Linux mode, Fn or left butterfly with P types `ps auxw|more` and Enter; H types `history` and Enter; keypad 0 sends the calculator launch key. L retains `ls -ltr` and Enter. Macro replay moves from Fn+P to Fn+O. Old default saved Fn bindings migrate without resetting deliberate remaps. Standard layers are unchanged. Includes v1.0.1 sleep fix.

Firmware build, mapping assertions, action/modifier regression tests, sleep tests and dictionary tests passed. Physical Ubuntu calculator launch and keyboard operation still require testing. No flashing performed.
