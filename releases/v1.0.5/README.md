# v1.0.5 - Idle rainbow invasion

The Linux rainbow starts spreading from right to left after ten seconds idle, reaching full keyboard coverage at two minutes since last activity. The moving edge blends with the live heatmap. Any key/knob activity triggers a half-second retreat to the continuously coloured number pad and symbol keys. Repeated typing does not prolong the retreat. Escape status, Fn highlights, Caps Lock warning, ordinary lighting off and sleep retain their existing behaviour. Stock modes and typing shortcuts are unchanged.

Build and host regression checks passed, including idle timing, partial/full coverage and retreat, repeated input, mapped encoder activity, clock rollover and prior feature checks. Hardware appearance and input/sleep behaviour need checking after flashing. No flashing performed. v1.0.4 is retained as a fallback.
